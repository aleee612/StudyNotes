### 错题
#### 整数
> 某字长为 8 位的计算机中，已知整型变量 x、y 的机器数分别为 x 补=1111 0100 ， y 补=1011 0000 。若整型变量 z=2x+y/2，则 z 的机器数为（ ）。
	A.11000000      B.00100100      C.10101010      D.溢出
- x的反码为1111 0011，则原码为1000 1100，十进制数为-12
- y的反码为1010 1111，则原码为1101 0000，十进制数为-80
- 说明此时的相加不会引起溢出
- `2*x`说明是算数左移，移动后为1110 1000；`y/2`说明是算数右移，补1，移动后为1101 1000
- 说明无精度丢失
- 相加后为 1100 0000

> 考虑以下 C 语言代码：
```c
unsigned short usi = 65535;
short si = usi;
```
> 执行上述程序段后，si 的值是（ ）。
	A.-1     B.-32767     C.-32768     D.-65535
- 在考研题通常采用的“16 位 `short`、补码、按低 16 位解释”的机器模型下，65535 即 $2^{16}-1$，其位模式 `1111 1111 1111 1111` 解释为有符号数时是 $-1$
- 但按 C 语言标准，若无符号值不能由目标有符号类型表示，转换结果由实现定义；脱离题目给定的机器模型时，不能把 $-1$ 当作跨平台保证
#### 浮点数
> float 类型（即 IEEE754 单精度浮点数格式）能表示的最大正整数是（ ）。
	A.$2^{126}−2^{103}$     B.$2^{127}−2^{104}$      C.$2^{127}−2^{103}$      D.$2^{128}−2^{104}$ 
- 最大有限规格化数的阶码字段为 254，实际指数为 $254-127=127$。
- 最大有效数为二进制 $1.111\cdots111=2-2^{-23}$。
- 因此最大有限正数为 $(2-2^{-23})2^{127}=2^{128}-2^{104}$，它恰好也是整数。

> IEEE 754 单精度浮点格式表示的数中，最小的规格化正数是 (  )
	A.$1.0×2^{−126}$      B.$1.0×2^{−127}$      C.$1.0×2^{−128}$      D.$1.0×2^{−149}$
- 规格化数的最小非零阶码字段为 1，实际指数为 $1-127=-126$，尾数最小为 $1.0$，故最小规格化正数为 $1.0\times2^{-126}$。
- $2^{-149}$ 是最小的正非规格化数，不是规格化数。

> 已知 float 型变量用 IEEE754 单精度浮点数格式表示。若 float 型变量 x 的机器数为 8020 0000H，则 x 的值（ ）
	A.$−2^{−128}$      B.$−1.01×2^{−127}$      C.$−1.01×2^{−126}$      D.非数 (NAN)
- 考察异常数，其中x展开后可得阶码为全0，而尾数为01，由此可套公式$±0.f×2^{1−bias}$ ，得出计算$-0.01*2 ^{1-127}$ 
- 最终结果为$−2^{−128}$
