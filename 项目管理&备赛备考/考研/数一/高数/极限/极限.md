### 函数极限
#### 性质
##### 唯一性
1. 存在的**充要**条件： 左右极限存在且都相等 -> $\displaystyle \lim _{x \to x_{0}}f(x)=A=\lim _{x \to x_{0}^-}f(x)=\lim _{x \to x_{0}^+}f(x)$ 
2. $x\to+\infty$ 与 $x\to-\infty$ 是两个独立的极限；只有题目讨论 $|x|\to\infty$（无方向的无穷远）时，才要求两者存在且相等。
3. 在分段函数中，需注意分段两侧的表达式是否相同
##### 局部有界性
> if ( $\displaystyle \lim _{x \to x_{0}}f(x)=A$  ){                  当极限存在
> 	存在 M>0, δ>0；               M、δ 是“存在”，不是“任意”
> 	if ( 0 < |$x-x_{0}$| < δ ){        当$x-x_{0}$在0~δ中
> 		|$f(x)$| ≤ M;                $f(x)$ 的绝对值小于M
> 	}
> }
1. 极限存在 => 函数有界（不可逆推）
2. $y=f(x)$ 在 `[a,b]` 上连续，则说明该函数在此区间有界
3. $y=f(x)$ 在 `(a,b)` 上连续，且 $\displaystyle \lim _{x \to a^+}f(x)$、$\displaystyle \lim _{x \to b^-}f(x)$ 都存在且为有限值，则 $f$ 在 `(a,b)` 上有界。
4. 两个有界函数的和、差、积仍为有界函数（商不一定有界）。这一结论的前提是参与运算的函数在所讨论范围内本身有界，不能泛化成“初等函数的和差积都自动有界”。
##### 局部保号性
> $\displaystyle \lim _{x \to x_{0}}f>0$     ->    在 $x_0$ 的某个去心邻域内，f > 0
> $\displaystyle \lim _{x \to x_{0}}f< 0$     ->    在 $x_0$ 的某个去心邻域内，f < 0
> f ≥ 0             ->    $\displaystyle \lim _{x \to x_{0}}f$ ≥ 0
> f ≤ 0             ->    $\displaystyle \lim _{x \to x_{0}}f$ ≤ 0

#### 无穷小
###### 定义： 在同一极限过程中（如 $x\to x_0$），若 $f(x)\to0$、$g(x)\to0$，且
$$\lim\frac{f(x)}{g(x)}=1,$$
则称 $f(x)$ 与 $g(x)$ 是**等价无穷小**，记作 $f(x)\sim g(x)$。
- 若 $\lim f/g=0$，则 $f$ 是比 $g$ 高阶的无穷小。
- 若 $\lim f/g=\infty$，则 $f$ 是比 $g$ 低阶的无穷小。
###### 常用等价：
$$x \sim \sin x \sim \tan x\sim \ln(1+x)\sim e^x-1$$
$$x-\ln(1+x)\sim 1-\cos x \sim \frac{x^2}{2}  $$
$$(1+x)^\alpha-1\sim \alpha x\quad(\alpha\ne0，\alpha为常数)$$
###### 性质：
- 乘除可直接替换：若 $f\sim g$，则 $\frac{f}{h}\sim\frac{g}{h}$、$fh\sim gh$ 
- 加减一般不能直接替换（$sinx−x\not\sim 0$）

### 数列极限
关于[[数列]]
#### 性质
##### 唯一性
与函数极限相同
##### 全局有界性
- 函数的有界性为局部，而数列强调全局有界
- 对数列中任意一项都有$|a_n|≤M$ 
##### 保号性
> $\displaystyle \lim _{n \to \infty}x_n=a>b$     ->   存在 N>0，当 n>N 时，有$x_n>b$ 
> $\displaystyle \lim _{n \to \infty}x_n=a<b$     ->   存在 N>0，当 n>N 时，有$x_n<b$ 
> $x_n≥b$ & $\displaystyle \lim _{n \to \infty}x_n=a$      ->      $a≥b$ 
> $x_n≤b$ & $\displaystyle \lim _{n \to \infty}x_n=a$      ->      $a≤b$ 
数列极限没有强调局部保号性，但也强调存在正整数N，当n>N时才有$a_n>0$或$a_n<0$
- 它的意义在于： 数列前 n 项是什么样（是正、是负、还是忽正忽负）统统不重要
- 只要极限 $A > 0$，那么总能找到一个“分水岭” $N$。在这个 $N$ 之后的所有项都为正数。

---
#### 有界
定义：存在正实数 $M$，使得对所有正整数 $n$，都有 $|a_n|≤M$。
> [!note] 几种方法证明有界
> 1. 找M
> 2. 放缩法
> 	1. $if： u_i\geq 0\Rightarrow1·u_{max} \leq u_1+u_2+···+u_n\leq n·u_{max}$ 
> 	2. $else： n·u_{min} \leq u_1+u_2+···+u_n\leq n·u_{max}$ 
> 3. 找最值
> 4. [[不等式|基本不等式]]
##### 单调有界准则 => 证极限存在
> 单增+上界 => 极限存在
> 单减+下界 => 极限存在
**证明单调：**
1. 作差法：$x_{n+1}-x_n\geq0$ ， $x_{n+1}-x_n\leq0$  
2. 作比法：在 $x_n>0$（或已明确符号）的前提下，用 $\frac{x_{n+1}}{x_n}\geq1$ 或 $\frac{x_{n+1}}{x_n}\leq1$ 判断单调性；符号未知时不能直接用比值与 1 比较
3. 数学归纳法：验$x_1$ -> 设$x_k$ -> 证$x_{k+1}$ 
4. 不等式
5. 压缩映射原理：
	1. 若 $0<k<1$ 且 $\left| x_{n+1}-a\right| \leq k\left| x_{n}-a\right|$，则 $\{x_n\}$ 收敛于 $a$。
	2. 若迭代为 $x_{n+1}=f(x_n)$，存在闭区间 $I$ 使 $f(I)\subseteq I$，且在 $I$ 上 $|f'(x)|\le k<1$，则 $f$ 在 $I$ 内有唯一不动点 $a$，并且从任意 $x_1\in I$ 出发的迭代数列都收敛于 $a$
