### 普通函数
| 项目    | 内容                                                                                                     |
| ----- | ------------------------------------------------------------------------------------------------------ |
| 函数    | $\displaystyle y=\frac1{\sqrt{1+x^2}}=(1+x^2)^{-\frac12}$                                              |
| 导数    | $\displaystyle y'=-\frac{x}{(1+x^2)^{3/2}}$                                                            |
| 原函数   | $\displaystyle \int\frac1{\sqrt{1+x^2}}\,dx=\ln\left(x+\sqrt{1+x^2}\right)+C=\operatorname{arsinh}x+C$ |
| 泰勒展开  | $\displaystyle 1-\frac12x^2+\frac38x^4-\frac5{16}x^6+\frac{35}{128}x^8+o(x^8)$                         |
| 定义域   | $\mathbb{R}$                                                                                           |
| 值域    | $(0,1]$                                                                                                |
| 奇偶性   | 偶函数                                                                                                    |
| 单调性   | $(-\infty,0)$ 递增；$(0,+\infty)$ 递减                                                                      |
| 最值    | 最大值为 $1$（$x=0$）                                                                                        |
| 渐近线   | 水平渐近线：$y=0$                                                                                            |
| 无穷远等价 | $\displaystyle \frac1{\sqrt{1+x^2}}\sim\frac1{x}\quad(x\to\infty)$                                     |
