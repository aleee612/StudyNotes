### 性质

设 $A$ 为 $n$ 阶方阵：

$$|A^T|=|A|,\qquad |AB|=|A||B|,\qquad |kA|=k^n|A|$$

若 $A$ 可逆：

$$|A^{-1}|=\frac1{|A|},\qquad |A^m|=|A|^m$$

| 操作 | 行列式变化 |
| --- | --- |
| 交换两行（列） | 变号 |
| 某行（列）乘 $k$ | 整个行列式乘 $k$ |
| 某行（列）的 $k$ 倍加到另一行（列） | 不变 |
| 两行（列）相同或成比例 | $0$ |
| 某行（列）全为 $0$ | $0$ |

三角矩阵、对角矩阵：

$$|A|=a_{11}a_{22}\cdots a_{nn}$$

分块三角矩阵：

$$
\left|\begin{matrix}A&B\\0&D\end{matrix}\right|
=|A||D|,\qquad
\left|\begin{matrix}A&0\\C&D\end{matrix}\right|
=|A||D|
$$

### 展开

元素 $a_{ij}$ 的代数余子式：

$$A_{ij}=(-1)^{i+j}M_{ij}$$

按第 $i$ 行或第 $j$ 列展开：

$$|A|=\sum_{j=1}^na_{ij}A_{ij}=\sum_{i=1}^na_{ij}A_{ij}$$

同一行元素与另一行对应代数余子式相乘后求和为 $0$：

$$\sum_{j=1}^na_{ij}A_{kj}=0\quad(i\ne k)$$

### 计算

| 结构 | 处理 |
| --- | --- |
| 某行或某列非零项少 | 按该行或列展开 |
| 各行（列）元素和相同 | 全部加到一行（列），提取公因子 |
| 每行结构相近 | 行（列）相减，制造大量 $0$ |
| 主对角线外元素相同 | 写成 $aE+b\boldsymbol1\boldsymbol1^T$ 或做行列变换 |
| 递推结构 | 按首行展开，或相邻行相减建立递推式 |
| 分块三角结构 | 化成分块上三角或下三角 |

范德蒙德行列式：

$$
\begin{vmatrix}
1&1&\cdots&1\\
x_1&x_2&\cdots&x_n\\
\vdots&\vdots&&\vdots\\
x_1^{n-1}&x_2^{n-1}&\cdots&x_n^{n-1}
\end{vmatrix}
=\prod_{1\le i<j\le n}(x_j-x_i)
$$

### 与矩阵的关系

$$|A|\ne0\Longleftrightarrow A\text{可逆}\Longleftrightarrow r(A)=n$$

伴随矩阵 $A^*$：

$$AA^*=A^*A=|A|E,\qquad |A^*|=|A|^{n-1}$$

若 $A$ 可逆：

$$A^{-1}=\frac1{|A|}A^*$$

克拉默法则只适用于方程个数与未知数个数相同且系数行列式非零的情形，见[[线性方程组]]。
