### 条件转换

| 已知                   | 可立即使用                                    |
| -------------------- | ---------------------------------------- |
| $\lvert A\rvert\ne0$ | $A$ 可逆、$r(A)=n$、齐次方程只有零解、$0$ 不是特征值       |
| $AB=E$，$A,B$ 同阶方阵    | $A,B$ 均可逆，$B=A^{-1}$，同时有 $BA=E$          |
| $AB=0$               | $R(B)\subseteq N(A)$，$r(A)+r(B)\le n$    |
| $A^2=A$              | 特征值只能为 $0,1$；$r(A)=\operatorname{tr}(A)$ |
| $A^2=E$              | 特征值只能为 $\pm1$；$A^{-1}=A$                 |
| $A^k=0$              | 特征值全为 $0$，$\lvert A\rvert=0$             |
| $A\sim B$            | 特征值、迹、行列式、秩相同                            |
| $A$ 实对称              | 正交对角化，不同特征值的特征向量正交                       |
| $A$ 正定               | 特征值全正、顺序主子式全正、可逆                         |

### 含参数

| 题目 | 先做 |
| --- | --- |
| 行列式为零或可逆 | 计算 $\lvert A\rvert$，找参数临界值 |
| 秩发生变化 | 行变换保留参数，或寻找非零子式；在可能作除数的位置分类 |
| 方程组解的数量 | 比较 $r(A)$、$r(A,\boldsymbol b)$ 与未知数个数 |
| 向量组相关性 | 把向量作列组成矩阵，比较秩与向量个数 |
| 已知特征值关系 | 使用特征多项式、迹与行列式 |
| 可相似对角化 | 比较各特征值的代数重数与几何重数 |
| 二次型正定 | 用特征值或顺序主子式分类 |

参数参与初等变换时，含参数的式子未确定非零前不能直接作为除数。

### 抽象矩阵

矩阵多项式可以直接作用于特征向量：

$$A\boldsymbol\xi=\lambda\boldsymbol\xi
\quad\Rightarrow\quad
f(A)\boldsymbol\xi=f(\lambda)\boldsymbol\xi$$

因式分解前先检查矩阵能否交换：

$$A^2-B^2=(A-B)(A+B)$$

只有在 $AB=BA$ 时成立。

若：

$$A^2+aA+bE=0$$

且 $b\ne0$，则：

$$A(A+aE)=-bE$$

所以 $A$ 可逆，并可直接写出：

$$A^{-1}=-\frac1b(A+aE)$$

### 线性无关的证明

证明 $A\boldsymbol\alpha_1,\ldots,A\boldsymbol\alpha_s$ 线性无关：

$$
k_1A\boldsymbol\alpha_1+\cdots+k_sA\boldsymbol\alpha_s=0
$$

整理为：

$$A(k_1\boldsymbol\alpha_1+\cdots+k_s\boldsymbol\alpha_s)=0$$

若 $A$ 可逆或 $N(A)=\{0\}$，再利用 $\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s$ 无关推出全部系数为 $0$。

线性映射后：

$$r(A\boldsymbol\alpha_1,\ldots,A\boldsymbol\alpha_s)
\le r(\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s)$$

一般不能由原向量组无关直接推出像向量组无关。

### 方程组与向量组

| 说法 | 等价条件 |
| --- | --- |
| $\boldsymbol b$ 可由 $A$ 的列向量表示 | $A\boldsymbol x=\boldsymbol b$ 有解 |
| $A$ 的列向量组无关 | $A\boldsymbol x=0$ 只有零解 |
| $A$ 的列向量组生成 $\mathbb R^m$ | 对任意 $\boldsymbol b\in\mathbb R^m$，$A\boldsymbol x=\boldsymbol b$ 有解 |
| $A$ 为 $n$ 阶且列向量构成一组基 | $A$ 可逆 |

### 特征值与方程组

$$
\lambda\text{是}A\text{的特征值}
\Longleftrightarrow
(A-\lambda E)\boldsymbol x=0\text{有非零解}
$$

$$
\Longleftrightarrow |A-\lambda E|=0
\Longleftrightarrow r(A-\lambda E)<n
$$

求 $A$ 对应 $\lambda$ 的线性无关特征向量个数：

$$n-r(A-\lambda E)$$

### 三种关系

| 条件 | 不能直接推出 |
| --- | --- |
| 矩阵等价 | 特征值相同、相似或合同 |
| 特征值相同 | 两矩阵相似 |
| 行列式和迹相同 | 两矩阵相似 |
| 两矩阵相似 | 两矩阵合同 |
| 两矩阵合同 | 两矩阵相似 |
| $\lvert A\rvert>0$ | $A$ 正定 |

判断相似时继续比较各特征值对应的几何重数；判断实对称矩阵合同关系时使用正、负惯性指数。
