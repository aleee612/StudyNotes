### 线性表示

$\boldsymbol\beta$ 可由 $\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s$ 线性表示：

$$\boldsymbol\beta=k_1\boldsymbol\alpha_1+\cdots+k_s\boldsymbol\alpha_s$$

等价于方程组：

$$[\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s]\boldsymbol k=\boldsymbol\beta$$

$$
\boldsymbol\beta\text{可表示}
\Longleftrightarrow
r(\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s)
=r(\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s,\boldsymbol\beta)
$$

### 线性相关

$$k_1\boldsymbol\alpha_1+\cdots+k_s\boldsymbol\alpha_s=\boldsymbol0$$

只有零解：线性无关；存在非零解：线性相关。

| 条件 | 结论 |
| --- | --- |
| 向量组含零向量 | 相关 |
| 向量个数大于向量维数 | 相关 |
| 向量组中某向量可由其余向量表示 | 相关 |
| 整体无关 | 任意子组无关 |
| 某个子组相关 | 整体相关 |
| $s$ 个 $n$ 维向量，$r=s$ | 无关 |
| $s$ 个 $n$ 维向量，$r<s$ | 相关 |

若 $\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_s$ 线性无关，而 $\boldsymbol\beta_1,\ldots,\boldsymbol\beta_t$ 均可由它们表示：

- $t>s$ 时，$\boldsymbol\beta_1,\ldots,\boldsymbol\beta_t$ 必相关。
- $\boldsymbol\beta_1,\ldots,\boldsymbol\beta_t$ 无关时，$t\le s$。

### 极大无关组与向量组的秩

- 极大无关组本身线性无关。
- 原向量组中的每个向量都可由极大无关组表示。
- 同一向量组的所有极大无关组所含向量数相同，该数即向量组的秩。
- 两个向量组能相互线性表示，称为等价向量组；等价向量组的秩相同。
- 秩相同不能单独推出两个向量组等价。

求列向量组的极大无关组：对矩阵做行变换找到主元列，再回到原矩阵取相同编号的列。

### 向量空间

| 概念 | 关系 |
| --- | --- |
| 基 | 空间中的极大线性无关组 |
| 维数 | 一组基所含向量的个数 |
| 坐标 | 向量在给定基下的唯一线性表示系数 |
| 子空间 | 对向量加法和数乘封闭的非空集合 |

$$\dim(U+V)=\dim U+\dim V-\dim(U\cap V)$$

齐次方程组 $A\boldsymbol x=0$ 的解空间维数：

$$\dim N(A)=n-r(A)$$

### 基变换与坐标变换

设两组基满足：

$$
(\boldsymbol\beta_1,\ldots,\boldsymbol\beta_n)
=(\boldsymbol\alpha_1,\ldots,\boldsymbol\alpha_n)P
$$

$P$ 为从基 $\alpha$ 到基 $\beta$ 的过渡矩阵。若同一向量在两组基下的坐标分别为 $X_\alpha,X_\beta$：

$$X_\alpha=PX_\beta,\qquad X_\beta=P^{-1}X_\alpha$$

### 内积与正交化

$$\langle\boldsymbol\alpha,\boldsymbol\beta\rangle=\boldsymbol\alpha^T\boldsymbol\beta,\qquad
\|\boldsymbol\alpha\|=\sqrt{\boldsymbol\alpha^T\boldsymbol\alpha}$$

$$\boldsymbol\alpha\perp\boldsymbol\beta\Longleftrightarrow\boldsymbol\alpha^T\boldsymbol\beta=0$$

非零正交向量组必线性无关。

施密特正交化：

$$\boldsymbol\beta_1=\boldsymbol\alpha_1$$

$$
\boldsymbol\beta_k=\boldsymbol\alpha_k-
\sum_{i=1}^{k-1}
\frac{(\boldsymbol\alpha_k,\boldsymbol\beta_i)}{(\boldsymbol\beta_i,\boldsymbol\beta_i)}
\boldsymbol\beta_i
$$

单位化：

$$\boldsymbol e_i=\frac{\boldsymbol\beta_i}{\|\boldsymbol\beta_i\|}$$

正交矩阵 $Q$：

$$Q^TQ=E\Longleftrightarrow Q^{-1}=Q^T$$

其行向量和列向量分别构成标准正交基，且 $|Q|=\pm1$。
