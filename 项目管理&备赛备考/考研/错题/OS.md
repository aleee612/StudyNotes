>  [[上下文切换]] **D**  ![[Pasted image 20260724142424.png]]
1. 在上下文切换 时，操作系统需要保存和恢复与当前进程相关的状态信息
2. **通用寄存器**、**页表基址寄存器**和**程序计数器**通常会在上下文切换时更新，以切换到新进程的上下文
3. 然而，**内核中断向量表基址寄存器**通常是**系统级**的，通常不会在每次上下文切换时更改，因此操作系统不需要在上下文切换时更新该寄存器

> [[文件#文件共享：软连接与硬链接]] **A** ![[Pasted image 20260801190915.png]]
1. 默认情况下为什么可以认为无硬链接？
	408 文件系统题目如果没有特别说明，一般默认：
	- file1 是普通文件
	- 没有其他硬链接指向它
	所以删除 file1：	
		删除目录项
		    ↓
		检查链接数
		    ↓
		链接数=0
		    ↓
		释放FCB
		    ↓
		释放磁盘空间
	因此 B、C 都认为需要删除
2. 那为什么A一定错？
	因为题目中的“链接”通常指**硬链接**，而A说删除 file1 的快捷方式，“快捷方式”是 Windows 概念，不是文件系统中的链接
	Linux/Unix 文件系统：
	- 硬链接：多个目录项指向同一个 inode
	- 符号链接：一个特殊文件，保存目标路径
	- Windows快捷方式：普通文件（.lnk）
	**删除 file1 时不会自动寻找并删除“快捷方式”**

> [[中断]] **D**
> ![[Pasted image 20260805113002.png]]
1. 保存被中断程序的中断点指的是 PC ，该操作由硬件完成
2. CPU 响应中断时，必须先由硬件自动保存该地址，才能跳转到中断服务程序
3. 中断屏蔽字决定当前允许或禁止响应哪些中断
4. 为了支持中断嵌套并在中断返回后恢复原来的屏蔽状态，操作系统需要保存和恢复中断屏蔽字
5. `IF` 确实是硬件寄存器中的标志位，但“中断屏蔽字”不等于 `IF`，而且“存放在硬件中”也不等于“由硬件自动保存”
6.   IF：可屏蔽中断的总开关
	屏蔽字：对各个中断源进行选择性控制

> **B** ![[Pasted image 20260805113704.png]]
1. CPU 不会在信号出现的一瞬间立即中断当前指令
2. 通常必须满足：
	- 当前指令执行完毕
	- CPU 处于开中断状态
	- 没有优先级更高的中断
	- 该中断没有被中断屏蔽字屏蔽
	- CPU 正常进行中断查询并确认请求
3. 通过中断屏蔽字，可以在处理某一级中断时屏蔽某些中断，允许另一些中断进入，或改变中断嵌套顺序
