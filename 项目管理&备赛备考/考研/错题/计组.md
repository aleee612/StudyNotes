> 总线 **D** ![[Pasted image 20260718153624.png]]
1. 存储总线的宽度为 64 位，代表每次数据传送可以传送 64bit 的数据
2. 总线时钟频率位 1GHZ，代表 1s 可以传送 1G 次，即 10⁹ 次/s，所以每个时钟周期为 10⁻⁹s = 1ns
3. 具体步骤为： CPU 通过地址线传输地址花费 1ns，主存准备数据 6ns，主存传输数据到 CPU 花费 1ns，共 8ns， 因为 32B 的数据在总线宽度为 64 位的总线上，需要传输 (32*8bit) / 64bit = 4 次
4. 因此读取一个 主存块的时间为 4×8ns=32ns
5. 不选择 C ：内存无法在准备一个数据的同时向总线传输数据或从总线接收地址，如果支持流水线或者突发传输，后续的地址和准备时间才有可能被部分重叠掩盖（比如算出 $1 + 6 + 4 \times 1 = 11\text{ ns}$ 或其他变体），但在本题**不支持突发传送**的严格限制下，只能乖乖串行执行

> [[内存管理单元MMU|MMU]] **B**
> ![[Pasted image 20260723150141.png]]
1. MMU负责将虚拟地址转化为物理地址
2. 会检测以下事件：访问越权、页面缺失、TLB 缺失
3. Cache 缺失不是在 MMU 地址转换过程中检测的，而是在 CPU 访问主存数据检测的
4. 访问主存的前提是**有物理地址**，所以该过程是在 MMU 完成地址翻译之后

> [[概念/计算机组成原理/存储/Cache|Cache]] **A** ![[Pasted image 20260801181818.png]]
1. **物理地址结构**：CPU访问内存时产生的地址，告诉系统“数据在主存哪里”
	| Tag | Cache 行号（索引） | 块内偏移 |
2. **Cache行结构**：Cache里面存储数据时，一个缓存单元长什么样
![[Pasted image 20260801184906.png]]
3. 通常认为**物理地址**和**主存地址**同大小，即32bit
4. 块内偏移计算：$块内偏移位数=\log_2(32B/1B)=5$。
5. 直接映射时，Cache 行数为 $32KB/32B=2^{10}$，所以行号（索引）占 10 位。
6. 标记位的计算：
$标记位=物理地址 - 块内偏移 - Cache 块号=32-5-10=17$
7. 本题采用直接映射和写回法，因此每个 Cache 行大小为 **标记位+有效位+脏位+数据块**，即 $17+1+1+256=275$ 位；若不是写回法，则不一定需要脏位。

>[[异常和中断]] **B** ![[Pasted image 20260801185023.png]]
1. DMA 请求只请求**总线的使用权**，不影响**当前指令**的执行，不会导致被中断指令的**重新执行** 
2. 当缺页中断发生后，必须回到这条指令重新执行，以便重新访存
3. 题目说异常事件在当前指令执行过程中进行检测，中断请求则在当前指令执行后进行检测，但 **“是否重新执行当前指令”不是由检测时间决定，而是由异常类型决定** ，题干属于干扰
4. 中断一般不会重新执行当前指令
5. 异常分类中：

| 类型        | 检测时机    | 是否重新执行当前指令 |
| --------- | ------- | ---------- |
| Fault（故障） | 指令执行过程中 | 返回地址通常指向当前指令；若故障可恢复（如缺页），处理后可重新执行 |
| Trap（陷阱）  | 指令执行后   | ❌ 否        |
| Abort（终止） | 指令执行过程中 | ❌ 无法恢复     |

> [[格式和寻址方式]]  **A** ![[Pasted image 20260805114047.png]]
1. “支持四种寻址方式”不等于 CPU 能默认知道当前指令使用哪一种
2. 机器执行每条指令时，必须从指令编码中判断本次使用的寻址方式
3. 因此不能认为在指令中默认包含了四种寻址方式
4. 由上可得，指令的寻址方式需要占用两位指令空间
5. 由 $48<2^6$ 可得，最终应选择 $2^{16-2-6}=2^8$
