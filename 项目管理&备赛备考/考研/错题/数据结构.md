> [[二叉树#平衡二叉搜索树 AVL]] **D** ![[Pasted image 20260801125814.png]]![[Pasted image 20260801125822.png]]

2. 由树可得，此时应为RL旋转
3. 先进行一次右旋，即
	```
	    20
	   /  \
	  16   25
	      /  \
	     23   30
	            \
	             40
	```
4. 再进行一次左旋，即	
	```
	       25
	      /  \
	    20    30
	   / \      \
	 16  23      40
	```
