### 寻址、转发与路由

#### 标识

| 标识 | 对象 | 相关机制 |
| --- | --- | --- |
| 域名 | 资源/主机名称 | [[DNS：目录服务|DNS]] |
| 端口号 | 主机内进程 | TCP/UDP 分用 |
| IP 地址 | 网络接口 | 路由器转发 |
| MAC 地址 | 本地链路接口 | 交换机转发、ARP |

#### 发送判断

```text
DNS 得到目的 IP
→ 用掩码判断是否同网段
→ 同网段：ARP 查目的主机 MAC
→ 不同网段：ARP 查默认网关 MAC
```

目的 MAC 是下一跳，目的 IP 是最终主机。

#### 转发与路由

- 转发：数据平面按 FIB/转发表逐分组处理；
- 路由选择：控制平面生成路由信息；
- 多项匹配时用 [[子网划分与路由聚合#最长前缀匹配|最长前缀匹配]]；
- 默认路由：`0.0.0.0/0`。

| 范围 | 协议 |
| --- | --- |
| AS 内 LS | [[OSPF开放最短路优先|OSPF]] |
| AS 内 DV | [[RIP 路由信息协议|RIP]] |
| AS 间路径向量 | [[BGP 边界网关协议|BGP]] |
