### 运输服务

- 提供进程到进程的逻辑通信；
- 使用 [[端口号]] 完成复用与分用；
- 运行在端系统，不运行在普通转发路由器上。

| 属性 | [[UDP]] | [[TCP]] |
| --- | --- | --- |
| 连接 | 无连接 | 面向连接 |
| 数据形态 | 报文 | 字节流 |
| 可靠、有序 | 不提供 | 提供 |
| 流量控制 | 无 | 有 |
| 拥塞控制 | 无 | 有 |
| 首部 | 8 B | 20～60 B |

> [!warning] TCP、UDP 均不保证固定时延和最低吞吐量，也不自带加密；安全性通常由 [[SSL|TLS]] 等提供。
