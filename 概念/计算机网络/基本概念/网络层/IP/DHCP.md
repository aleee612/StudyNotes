### DHCP 动态主机配置协议

> DHCP 是应用层的客户—服务器协议，使用 UDP，使主机能够自动取得网络配置，因此也常称为即插即用协议或零配置协议。

#### DHCP 能提供的配置

- IPv4 地址及租期；
- 子网掩码；
- 默认网关；
- DNS 服务器地址；
- 其他可选配置参数。

DHCP 不只是“根据 MAC 地址查 IP”。客户端报文中可以包含硬件地址或客户端标识，服务器根据地址池、租约和配置策略分配参数。

#### 地址分配方式

- **自动分配**：服务器为主机长期分配一个地址。
- **动态分配**：从地址池中分配具有租期的地址，是最常见的方式。
- **人工分配**：管理员预先建立客户端标识与固定地址的绑定。

#### 运输层端口

| 参与方 | UDP 端口 |
| --- | ---: |
| DHCP 服务器 | 67 |
| DHCP 客户端 | 68 |

#### DORA 过程

![[Pasted image 20251021084612.png]]

1. **DHCPDISCOVER（发现）**
   - 客户端尚无可用地址时，源 IP 通常为 `0.0.0.0`，目的 IP 为 `255.255.255.255`。
   - 用于寻找本链路上的 DHCP 服务器或中继代理。
2. **DHCPOFFER（提供）**
   - 服务器提出可分配的 IP 地址、掩码、租期等参数。
   - 在客户端尚不能稳定接收单播时可使用广播发送。
3. **DHCPREQUEST（请求）**
   - 客户端声明选择的服务器和地址，使其他服务器撤回各自的提议。
4. **DHCPACK（确认）**
   - 被选择的服务器确认租约和配置，客户端随后使用该地址。

速记：Discover → Offer → Request → ACK，即 **DORA**。

#### DHCP 中继代理

路由器通常不转发链路层广播，因此 DHCP 客户端与服务器不在同一子网时，需要中继代理：

1. 中继代理接收客户端广播；
2. 将请求以单播等方式转发给远端 DHCP 服务器；
3. 把服务器响应送回客户端所在链路。

> 中继代理不是 DHCP 服务器。它负责跨子网转发 DHCP 报文，真正的租约和地址池仍由服务器管理。

#### 租约更新

- 客户端通常在租期尚未到期时发送 DHCPREQUEST 请求续租。
- 若原服务器没有响应，客户端随后扩大请求范围，尝试与其他可用服务器重新绑定。
- 租约到期而未续租成功时，客户端不能继续使用该地址。

#### IP 地址资源的分配层级

公网地址块大体按以下层级管理：

```text
IANA
  ↓
RIR（区域互联网注册管理机构，如 APNIC）
  ↓
ISP / LIR 或大型组织
  ↓
下级网络或用户
```

- **ICANN** 负责互联网名称和号码体系的总体协调；IANA 职能由 ICANN 体系下的相关机构执行。
- **IANA** 管理全球 IP 地址池并向 RIR 分配大地址块。
- **RIR** 按区域向 ISP、LIR 或组织分配地址资源。
- DHCP 是具体网络内部自动配置主机参数的协议，不负责全球地址资源治理。
