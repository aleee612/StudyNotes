### 应用访问与安全

#### HTTPS 主线

```text
DHCP 配置网络参数（必要时）
→ DNS 获得服务器 IP
→ ARP 获得下一跳 MAC
→ TCP 三次握手
→ TLS 握手
→ HTTP 请求/响应
```

#### 协议分工

| 协议/机制 | 作用 |
| --- | --- |
| [[DHCP]] | IP、掩码、网关、DNS、租期 |
| [[DNS：目录服务|DNS]] | 域名 → IP |
| [[链路层寻址 & ARP|ARP]] | 下一跳 IPv4 → MAC |
| [[TCP]] | 可靠、有序字节流 |
| [[SSL|TLS]] | 加密、完整性、身份鉴别 |
| [[Web和HTTP|HTTP]] | 请求与响应语义 |
| [[Cookie]] / Session / Token | 应用状态 |

#### TLS 必考

- 证书链、域名、有效期、签名验证；
- 密钥交换后派生会话密钥；
- 对称加密保护应用数据；
- 服务器不会把私钥发送给客户端。

> [!warning]
> - DNS 不解析 MAC；ARP 不解析域名。
> - TCP 本身不加密。
> - 数字签名不提供机密性。
> - NAT 不是完整安全机制。
