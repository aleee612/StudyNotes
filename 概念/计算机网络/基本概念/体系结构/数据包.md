### 各层数据单位

| 层次 | 准确名称 | 示例 |
| --- | --- | --- |
| 应用层 | 应用报文 message | HTTP 请求、DNS 报文 |
| 运输层 | TCP 报文段 segment / UDP 用户数据报 datagram | TCP 首部加数据 |
| 网络层 | IP 数据报 datagram / 分组 packet | IPv4 数据报 |
| 数据链路层 | 帧 frame | 以太网帧 |
| 物理层 | 比特 bit | 在线路上传输的 0、1 |

日常交流中“包”可能泛指任何网络数据，但这些名称在分层题中有本质区别：它们对应不同协议数据单元、不同首部和不同处理设备。

例如路由器收到以太网帧后，先去掉旧帧首尾得到 IP 数据报，再为下一条链路生成新帧；它不是把原帧原样穿过所有网络。
