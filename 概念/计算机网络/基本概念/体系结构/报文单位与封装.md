### 报文单位与封装

#### 数据单位

| 层次 | PDU | 分用依据 |
| --- | --- | --- |
| 应用层 | 报文 | 应用协议字段 |
| 运输层 | TCP 报文段 / UDP 用户数据报 | 目的端口 |
| 网络层 | IP 数据报 | IPv4 协议字段 / IPv6 下一个首部 |
| 数据链路层 | 帧 | 类型字段 |
| 物理层 | 比特 | — |

#### 封装

```text
应用报文
→ TCP/UDP 首部
→ IP 首部
→ 链路层首部与尾部
→ 比特
```

#### 设备

| 设备 | 处理层次 | 转发依据 |
| --- | --- | --- |
| 集线器 | 物理层 | 无 |
| 二层交换机 | 数据链路层 | MAC 地址表 |
| 路由器 | 网络层 | IP 转发表 |

> [!warning]
> - 经过路由器：MAC、FCS 逐跳改变，TTL 减 1；普通转发时最终源、目的 IP 不变。
> - [[NAT]] 可修改 IP，NAPT 还可修改端口。
> - [[MTU与IP分片|MTU]] 包含 IP/TCP 首部，不包含链路层首尾；[[MSS最大报文长度|MSS]] 只指 TCP 数据。
