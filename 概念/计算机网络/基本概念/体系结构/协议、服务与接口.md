### 协议三要素
| 要素     | 规定内容                    | 记法      | 例子                  |
| ------ | ----------------------- | ------- | ------------------- |
| 语法     | 数据与控制信息的格式、结构、字段顺序和编码   | 怎么讲     | 首部有多少位、各字段放在哪里      |
| 语义     | 各字段或控制信息的含义，以及收到后应采取的动作 | 讲什么、做什么 | SYN=1 表示请求建立 TCP 连接 |
| 同步（时序） | 事件的先后顺序、速度匹配和时间关系       | 何时讲     | 先发送请求再等待响应、超时后重传    |
语法正确不代表语义正确；双方还必须按照规定的时序交互

### 协议、服务与接口
| 概念  | 关系            | 内容         |
| --- | ------------- | ---------- |
| 协议  | 同层对等实体之间，水平关系 | 规定通信规则     |
| 服务  | 下层向上层提供，垂直关系  | 上层能够使用的功能  |
| 接口  | 相邻两层之间        | 规定如何访问下层服务 |
本层使用下层服务，按照本层协议完成通信，再向上层提供服务

### 数据单位

$$\text{PDU}=\text{SDU}+\text{PCI}$$

| 名称  | 含义                     |
| --- | ---------------------- |
| SDU | 上层交给本层的数据              |
| PCI | 本层加入的协议控制信息，通常表现为首部或尾部 |
| PDU | 本层对等实体之间逻辑交换的数据单位      |
封装：SDU 加上本层 PCI 形成 PDU；解封装：接收方检查并去掉本层 PCI，将 SDU 交给上层
