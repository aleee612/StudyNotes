### 单道批处理系统
**自动性：** 无人工
**顺序性：** 先调入内存的作业先完成
**单道性：** 内存中只有一道程序运行
### 多道批处理系统
**多道**：内存中有多道程序运行，相互独立
**宏观与微观：**
- 宏观上并行，微观上串行
**特性：**
- 有在外存的作业队列，根据算法调入内存
- 通过中断在程序暂停运行时运行另一道程序
- 具有自动性

| 对比项      | 单道批处理                  | 多道批处理                  |
| -------- | ---------------------- | ---------------------- |
| 内存中的用户程序 | 一道                     | 多道同时驻留                 |
| CPU 使用方式 | 当前作业等待 I/O 时，CPU 也可能空闲 | 当前作业等待 I/O 时，切换到其他就绪程序 |
| 主要目的     | 实现作业自动连续处理             | 提高 CPU 与设备利用率、提高吞吐量    |
| 执行特征     | 自动性、顺序性、单道性            | 多道性、宏观并行、微观串行          |
| 优点       | 减少人工干预                 | 资源利用率和系统吞吐量高           |
| 缺点       | CPU 与 I/O 设备利用率低       | 无交互能力、作业周转时间较长         |
| 核心考法     | 为什么利用率低                | 多道程序设计如何提高利用率          |
