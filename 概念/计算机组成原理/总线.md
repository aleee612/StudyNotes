### 分类
#### 按功能分类
| 类型         | 作用                       |
| ---------- | ------------------------ |
| 核内总线       | 连接 CPU 内部各部件（寄存器、ALU 等）  |
| 系统总线       | 连接 CPU、主存和 I/O 接口（408重点） |
| 通信总线（外部总线） | 计算机与外部设备或其他计算机通信         |
#### 按数据传送方式分类
| 串行总线           | 并行总线                       |
| -------------- | -------------------------- |
| 一次传 1 位        | 一次传多位                      |
| 速度高、抗干扰强、适合远距离 | 速度快、适合近距离                  |
| USB、PCIe、SATA  | DDR 内存总线、PCI、ISA、IDE(PATA) |
> 现代高速总线几乎都是串行总线
#### 按定时方式分类
| 同步总线      | 异步总线       |
| --------- | ---------- |
| 公共时钟控制    | 握手信号控制     |
| 适合速度接近的设备 | 适合速度差异大的设备 |
| 总线不能过长    | 不受统一时钟限制   |

---
### 结构
| 结构   | 特点                           |
| ---- | ---------------------------- |
| 单总线  | 所有设备共用一条总线，结构简单，但易产生瓶颈       |
| 多总线  | CPU、主存、I/O 分别使用不同总线，提高并行性    |
| 分层总线 | 按速度分层，高速设备直连 CPU，低速设备经桥接芯片连接 |
### 系统总线组成
| 总线                | 功能              |
| ----------------- | --------------- |
| 数据总线（Data Bus）    | 传输数据            |
| 地址总线（Address Bus） | 传输地址，决定寻址范围     |
| 控制总线（Control Bus） | 传输读写、时钟、中断等控制信号 |
**注意：**
- 数据总线宽度影响一次可传输的数据量
- 地址总线宽度决定最大寻址空间
- 控制总线传输控制信号，不传输数据

### 性能指标
| 指标     | 含义                     |
| ------ | ---------------------- |
| 时钟频率   | 时钟脉冲频率（Hz）             |
| 总线传输周期 | 一次总线传输所需时间（通常包含多个时钟周期） |
| 工作频率   | 实际传输数据的频率              |
| 总线宽度   | 数据总线位数（8、16、32、64 位）   |
| 总线带宽   | 单位时间最大传输数据量            |
#### 常用公式
$$
T=\frac1f
$$

$$
工作频率=\frac{时钟频率}{N}
$$
其中：
- $N$ 为一次总线传输包含的时钟周期数
若采用：
- SDR：工作频率 = 时钟频率
- DDR：工作频率 = 2 × 时钟频率
- QDR：工作频率 = 4 × 时钟频率
总线带宽：
$$
带宽=\frac{总线宽度}{8}\times 工作频率
$$

### 常见总线标准
| 总线            | 类型   | 传输方式 | 典型用途              |
| ------------- | ---- | ---- | ----------------- |
| ISA           | 系统总线 | 并行   | 最早的系统总线，已淘汰       |
| EISA          | 系统总线 | 并行   | ISA 扩展，兼容 ISA     |
| VESA          | 局部总线 | 并行   | 显卡等高速设备（已淘汰）      |
| PCI           | 局部总线 | 并行   | 显卡、网卡、声卡等扩展卡      |
| AGP           | 局部总线 | 并行   | 显卡专用接口，已被 PCIe 取代 |
| PCIe          | 局部总线 | 串行   | 显卡、NVMe SSD 等高速设备 |
| RS-232C       | 设备总线 | 串行   | DTE 与 DCE 串行通信    |
| USB           | 设备总线 | 串行   | 鼠标、键盘、U盘等外设       |
| PCMCIA        | 设备总线 | 并行   | 笔记本扩展卡（已淘汰）       |
| IDE（ATA/PATA） | 设备总线 | 并行   | 老式 HDD、光驱         |
| SCSI          | 设备总线 | 并行   | 服务器、工作站存储设备       |
| SATA          | 设备总线 | 串行   | HDD、SATA SSD、光驱   |

| 类型              | 包含                                    |
| --------------- | ------------------------------------- |
| **系统总线**        | ISA、EISA                              |
| **局部总线**        | VESA、PCI、AGP、PCIe                     |
| **设备总线（I/O总线）** | RS-232C、USB、PCMCIA、IDE、SCSI、SATA      |
| **串行总线**        | PCIe、RS-232C、USB、SATA                 |
| **并行总线**        | ISA、EISA、VESA、PCI、AGP、PCMCIA、IDE、SCSI |

### 总线、接口、协议
| 名称  | 含义     | 例子            |
| --- | ------ | ------------- |
| 接口  | 硬件连接位置 | USB-A、M.2     |
| 协议  | 通信规则   | USB、NVMe、AHCI |
| 总线  | 数据传输通路 | USB、PCIe、SATA |
**注意：**
- PCIe、USB、SATA 既可表示总线，也可表示接口和协议；
- M.2 只是接口，NVMe 只是协议

### 总线事务
> 总线事务是一次完整的数据传输过程

包括五个阶段：

| 阶段 | 内容 |
|------|------|
| 请求（Request） | 主设备申请总线 |
| 仲裁（Arbitration） | 决定哪个设备获得总线 |
| 寻址（Addressing） | 给出目标地址 |
| 传输（Transfer） | 读/写数据 |
| 终止（Termination） | 撤销控制，释放总线 |

---
### 突发传输（Burst）
>一次申请总线后，连续传输多个数据，而无需重复寻址

**优点：**
- 减少地址和控制开销
- 提高总线利用率
- 适合 DMA、缓存行填充等块数据传输

---
### 总线周期
> 总线周期是 CPU 完成一次总线操作所需时间

通常包括四个阶段：
1. 申请
2. 寻址
3. 数据传输
4. 结束

### 总线定时
#### 同步定时 VS 异步定时
| 同步定时        | 异步定时      |
| ----------- | --------- |
| 公共时钟控制      | 握手信号控制    |
| 总线周期固定      | 总线周期可变    |
| 所有设备按统一节拍工作 | 双方协调完成传输  |
| 控制简单，成本低    | 控制复杂，但效率高 |
| 适合速度接近设备    | 适合速度差异大设备 |
> 口诀：**同步看时钟，异步靠握手**
#### 异步定时三种方式
| 方式  | 特点                   | 口诀      |
| --- | -------------------- | ------- |
| 不互锁 | 双方都不等待               | 都不等     |
| 半互锁 | **发送方等接收方**，接收方不等发送方 | 发等收     |
| 全互锁 | 双方互相等待               | 你等我，我等你 |
> **可靠性：** 不互锁 < 半互锁 < 全互锁  
> **速度：** 不互锁 > 半互锁 > 全互锁
