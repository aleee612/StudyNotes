### 插入排序
> 每次将一个待排序的记录，按其关键字大小插入到前面已经排好序的子序列中，直到所有记录都插入完毕
#### 直接插入排序
> 适用于**顺序存储**和**链式存储**的线性表，采用链式存储时无须移动元素
1. 查找$L(i)$在$L[1⋯,i-1]$中的插入位置$k$
2. 将$L[k⋯,i-1]$中的所有元素依次后移一个位置
3. 将$L(i)$放入位置$k$ 
```cpp title=直接插入
void InsertSort(ElemType A[],int n){
	int i,j;
	for(i=2;i<=n;i++) //依次将A[2]～A[n]插入前面已排序序列 
		if(A[i]<A[i-1]){ //若A[i]关键码小于其前驱，将A[i]插入有序表 
			A[0]=A[i]; //复制为哨兵，A[0]不存放元素 
			for(j=i-1;A[0]<A[j];--j)//从后往前查找待插入位置 
				A[j+1]=A[j]; //向后挪位 
			A[j+1]=A[0]; //复制到插入位置
		}
}	
```
###### 效率
- 时间：$O(n^2)$
- 空间：$O(1)$ 
#### 折半插入排序
> 仅适用于**顺序存储**的线性表
1. 先通过**折半查找**确定插入位置，再**统一移动**元素
2. 当排序表采用**顺序**存储时，可以在查找有序子表时使用折半查找来提高效率
3. 一旦确定了插入位置，便可将该位置及其后的所有元素统一后移一位，从而空出插入位置
```cpp
void BInsertsort(ElemType A[],int n){
	inti,j,low,high,mid;
	for(i=2;i<=n;i++){ //依次将A[2]～A[n]插入前面的已排序序列 
		A[0]=A[i] //将A[i]暂存到A[0] 
		low=1;high=i-1; //设置折半查找的范围 
		while(low<=high){ //折半查找(默认递增有序) 
			mid=(low+high)/2; //取中间点 
			if(A[mid]>A[0]) high=mid-1;//查找左半子表 
			else low=mid+1; //查找右半子表
		} 
		for(j=i-1;j>=high+1;--j) 
			A[j+1]=A[j]; //统一后移元素，空出插入位置 
		A[high+1]=A[0]; //插入操作 
	}
} 
```
###### 效率
- 时间：$O(n^2)$
- 空间：$O(1)$ 
#### 希尔排序
> 仅适用于**顺序存储**的线性表
1. 算法首先选取一个小于$n$的初始增量$d$，将待排序表划分为$d_i$个子序列
2. 每个子序列包含下标间隔为d的记录
3. 对各子序列分别进行直接插入排序
4. 随后依次取更小的增量$d_2,d_3,⋯(满足d_2>d_3>⋯>d_i=1)$，重复分组与排序操作
5. 当增量减至1时，所有记录属于同一子序列，且序列已高度有序，此时执行最后一趟直接插入排序，即可快速获得最终结果
![[Pasted image 20260719135800.png]]
```cpp
void Shellsort(ElemType A[],int n){ 
//A[0]只是暂存单元，不是哨兵，当j<=0时，插入位置已到 
	int dk,i,j; 
	for(dk=n/2;dk>=1;dk=dk/2) //增量变化(无统一规定) 
		for(i=dk+1;i<=n;++i) 
			if(A[i]<A[i-dk]){ //需将A[i]插入有序增量子表 
				A[0]=A[i]; //暂存在A[0] 
				for(j=i-dk;j>0&&A[0]<A[j];j-=dk) 
					A[j+dk]=A[j]; //记录后移，查找插入的位置 
				A[j+dk]=A[0];
			}
}
```
###### 效率
- 时间：依赖于所选增量序列，n在常见范围：$O(n^{1.3})$，最坏：$O(n^2)$ 
- 空间：$O(1)$

### 交换排序
#### 冒泡排序
> 最小元素如气泡上浮至水面
```cpp
void Bubblesort(ElemType A[],int n){ 
	for(int i=0;i<n-1;i++){ 
		bool flag=false; //表示本趟冒泡是否发生交换的标志 
		for(int j=n-1;j>i;j--) //一趟冒泡过程 
			if(A[j-1]>A[j]){ //若为逆序 
				swap(A[j-1],A[j]); //使用封装的swap 函数交换 
				flag=true; 
			}
		if(flag==false) 
			return; //本趙遍历后没有发生交换，说明表已经有序
	}
}
```
###### 效率
- 时间：$O(n^2)$
- 空间：$O(1)$ 
#### 快速排序
> 平均性能最优的排序方法，仅适用于顺序存储的线性表
1. 在待排序表$L[1⋯.n]$中任取一个元素作为枢轴(pivot，也称基准， 通常取首元素)
2. 通过一趟排序将原表划分为两个独立的子表$L[1..k-1]$和$L[k+1⋯.n]$
3. 使得左子表中所有元素的关键字均小于枢轴，右子表中所有元素的关键字均大于或等于枢轴
4. 此时，枢轴元素被放在了其最终位置$L(k)$上，这个过程称为一次划分
5. 分别对两个子表递归地执行相同的划分操作，直至每个子表仅包含一个元素或为空，此时整个序列已完全有序
```cpp
int Partition(ElemType A[],int low,int high){ //一趟划分 
	ElemType pivot=A[low]; //将当前表中第一个元素设为枢轴，对表进行划分 
	while(low<high){ //循环跳出条件 
		while(low<high&&A[high]>=pivot)
			--high; 
		A[low]=A[high]; //将比枢轴小的元素移动到左端 
		while(low<high&&A[low]<=pivot)
			++low; 
		A[high]=A[low];//将比枢轴大的元素移动到右端
	}
	A[low]=pivot; //枢轴元素存放到最终位置 
	return low; //返回存放枢轴的最终位置
}
```
###### 效率
- 时间：最好：$O(nlog_2n)$，最坏：$O(n^2)$ 
- 空间：最好：$O(log_2n)$，最坏：$O(n)$

### 选择排序
#### 简单选择排序
> 第 $i$ 趟排序从 $L[i,⋯,n]$ 中选出关键字最小的元素，并将其与 $L(i)$ 交换
> 每一趟排序均可确定一个 元素的最终位置
```cpp
void SelectSort(ElemType A[],int n){ 
	for(int i=0;i<n-1;i++){ //共进行n-1趟
		int min=i;       //记录最小元素位置
		for(int j=i+1;j<n;j++) //在A[i...n-1]中选择最小元素
			if(A[j]<A[min])min=j; //更新最小元素位置
		if(min!=i) 
			swap(A[i],A[min]);     //swap()函数共移动元素3次
	}
}
```
###### 效率
- 时间：$O(n^2)$ 
- 空间：$O(1)$ 
#### 堆排序（小根堆为例）
[[堆排序]] 
###### 插入
- 将新元素插入到堆的最后一个位置
- 将该结点与其父结点比较
- 若新结点小于父结点，则交换两者位置
- 重复步骤2、3，直到到达根结点或父结点小于等于当前结点
###### 删除
- 删除堆顶元素，并将最后一个元素移到堆顶
- 将当前结点与左右孩子中**较小**的结点比较
- 若当前结点大于较小的孩子，则交换两者位置
- 重复步骤2、3，直到当前结点没有孩子或当前结点小于等于两个孩子
###### 构建
1. 将无序序列按顺序存入数组，视为一棵**完全二叉树**
2. 从**最后一个非叶子**结点开始（下标为 (n-2)/2）
3. 对当前结点进行**下滤**：与左右孩子中**较小**的那个比较，若当前结点较大，则交换，并继续向下调整，直到满足小根堆性质或到达叶子结点
4. 依次向前处理每个非叶子结点，直到根结点调整完成，整个序列即构成小根堆
###### 效率
- 时间：$O(nlog_2n)$ 
- 空间：$O(1)$

### 归并，基数，计数
> [[计数 & 基数]] 
#### 归并
> 采用**分治法**，将两个有序子序列合并成一个有序序列
1. 将待排序序列从中间划分为**两个子序列**
2. 对左右子序列**分别递归**进行归并排序
3. 待左右子序列均有序后，调用 Merge 合并
4. 重复上述过程，直到整个序列有序
###### 高频考点
- **递归终止条件**：`low >= high`（子序列长度≤1）
- **Merge 调用时机**：左右子序列均有序后（后序递归）
- **归并趟数**：$\lceil\log_2n\rceil$（若 $n=2^k$，则为 $\log_2n$）
- **每趟 Merge 调用次数**：$\dfrac{n}{2h}$​（$h$ 为当前有序段长度）
- **Merge 前提**：两个待合并子序列必须已有序
- **需要辅助数组**，因此**不是原地排序**
- 适用于顺序存储和链式存储（尤其适合链表）
###### 效率
- **时间**：$最好 = 平均 = 最坏 = O(n\log_2n)$
- **空间**：$O(n)$
