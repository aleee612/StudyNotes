### 核心规则
- 后序遍历次序：**左子树 → 右子树 → 根结点**
- 线索化只利用二叉链表中的空指针，不改变原有孩子指针
- `lchild` 为空时指向后序前驱，`rchild` 为空时指向后序后继

| 标志 | 0 | 1 |
| --- | --- | --- |
| `ltag` | `lchild` 指向左孩子 | `lchild` 指向后序前驱 |
| `rtag` | `rchild` 指向右孩子 | `rchild` 指向后序后继 |

> [!important] 线索数量
> 含 $n$ 个结点的二叉链表有 $2n$ 个孩子指针、$n-1$ 条孩子边，因此共有 $n+1$ 个空链域可用于线索化。没有头结点时，后序首结点的前驱和根结点的后继为 `NULL`。

### 做线索化题

先写出完整后序序列，再按序列填写空链域。设当前访问结点为 `p`，前一个访问结点为 `pre`：

| 条件 | 操作 |
| --- | --- |
| `p->lchild == NULL` | `p->ltag=1`，令 `p->lchild=pre` |
| `pre != NULL && pre->rchild == NULL` | `pre->rtag=1`，令 `pre->rchild=p` |
| 当前结点处理完毕 | 令 `pre=p` |
| 全部访问结束 | 根结点是最后一个结点，其后继为 `NULL` |

> [!tip] 最稳做法
> 若后序序列为 $v_1,v_2,\ldots,v_n$：无左孩子的 $v_i$ 才能把左指针指向 $v_{i-1}$；无右孩子的 $v_i$ 才能把右指针指向 $v_{i+1}$。先判断指针是否为空，再画线索。

### 查找前驱

后序中，结点 `p` 在自己的左右子树之后被访问，因此前驱可直接判断：

| 条件 | `p` 的后序前驱 |
| --- | --- |
| 有右孩子，即 `rtag=0` | 右孩子 |
| 无右孩子但有左孩子，即 `rtag=1、ltag=0` | 左孩子 |
| 左右孩子均不存在，即 `rtag=1、ltag=1` | `lchild` 所指的前驱线索 |
| `p` 是后序首结点 | 不存在，为 `NULL` |

因此，从最后访问的根结点开始不断寻找前驱，可以逆向遍历后序线索二叉树。

### 查找后继

| 条件 | `p` 的后序后继 |
| --- | --- |
| `rtag=1` | `rchild` 已直接指向后继 |
| `p` 是根结点 | 不存在，为 `NULL` |
| `p` 是双亲的右孩子 | 后继是双亲 |
| `p` 是双亲的左孩子，且双亲没有右子树 | 后继是双亲 |
| `p` 是双亲的左孩子，且双亲有右子树 | 后继是双亲右子树中第一个被后序访问的结点 |

寻找某棵子树中第一个被后序访问的结点：从子树根开始，有左孩子就向左走，否则有右孩子就向右走，直到不能再沿真实孩子指针下降。

> [!warning] 后序线索树的特殊难点
> 当 `rtag=0` 时，右指针是孩子而不是后继线索，仅靠左右孩子指针无法向上找到双亲。因此，正向后序遍历通常还需要双亲指针或辅助栈；这正是后序线索树与中序线索树最常见的辨析点。

### 高频判断

| 说法                 | 结论                            |
| ------------------ | ----------------------------- |
| 线索化会增加结点数量         | 错，只改造空链域并增加标志位                |
| 所有左指针都指向前驱         | 错，只有原本为空且 `ltag=1` 的左指针才是前驱线索 |
| 所有右指针都指向后继         | 错，只有原本为空且 `rtag=1` 的右指针才是后继线索 |
| 根结点是后序遍历的最后一个结点    | 对                             |
| 后序线索树一定能不借助栈完成正向遍历 | 错，缺少双亲指针时通常不能                 |
| 后序线索树容易从根开始逆向遍历    | 对，因为前驱容易确定                    |
